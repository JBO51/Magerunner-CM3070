# Magerunner
CM3070 Computer Science Final Project

<img width="1280" height="720" alt="cover read me" src="https://github.com/user-attachments/assets/10adc6ef-36ca-4ed1-bc4b-46c3e33bb6ff" />

To play the game, click on the **Releases** tab on the right hand side, and download the zip file for either the 144FPS or 240FPS build. 

Extract the Zip File then run **Magerunner.exe** to start the game.

It is recommended to use the 240FPS build on modern hardware, as it provides a smoother experience. 

The 144FPS build is designed for legacy hardware which could overheat trying to maintain 240FPS.
